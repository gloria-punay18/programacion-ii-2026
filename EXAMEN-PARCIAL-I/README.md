### Descripción del programa
Programa en Java que simula las operaciones básicas de un cajero automático para una cuenta bancaria. Incluye autenticación con PIN (2026), consulta de saldo, depósitos, retiros normales y con comisión mediante métodos sobrecargados, y un resumen final de la sesión.

### Indicación de cómo ejecutar la clase principal
Ejecute la clase principal `CajeroAutomatico.java` desde su entorno de desarrollo (IDE) o consola, e ingrese el PIN de acceso `2026` cuando el sistema lo solicite.
