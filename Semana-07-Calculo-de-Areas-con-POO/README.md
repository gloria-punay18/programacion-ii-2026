# Cálculo de Áreas con POO

## Breve descripción
Aplicación de consola en Java que calcula el área de diversas figuras geométricas implementando abstracción, encapsulamiento, herencia y polimorfismo mediante una clase base abstracta.

## Figuras implementadas
- **Círculo:** `Área = π × radio²`
- **Rectángulo:** `Área = base × altura`
- **Triángulo:** `Área = (base × altura) / 2`

1. **Requisito:** Tener instalado Java JDK.
2. Abre la terminal en la raíz del proyecto.
3. Compila el código fuente ubicado en la carpeta `src/`:
