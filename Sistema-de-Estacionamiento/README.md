## Descripción del programa

Programa en Java que simula la gestión y control de un parqueo o estacionamiento de vehículos (Automóviles y Motocicletas). Incluye el registro de vehículos, validación de placas únicas, búsqueda por número de placa, listado de vehículos registrados, cálculo del total general recaudado, desglose de ingresos por tipo de vehículo y manejo de excepciones ante entradas inválidas, integrado con una base de datos en PostgreSQL.

## Indicación de cómo ejecutar la clase principal

Ejecute la clase principal `Main.java` desde su entorno de desarrollo (IntelliJ IDEA) o consola. Asegúrese de haber ejecutado previamente el script `database/estacionamiento.sql` en PostgreSQL para contar con la estructura de la base de datos necesaria.
